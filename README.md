# SysReadout Monitor

**Everything your Android phone will tell you about itself, drawn as a KDE Konsole terminal.**

SysReadout Monitor (SR Monitor, SRM) groups hardware, CPU, memory, power, network, apps,
sensors, storage and a live event journal into pages you swipe between. Each page looks like a
Konsole session on Fedora: Breeze colours, the Hack font, a bash prompt and a blinking cursor.

It only works while you look at it, and only for the page on screen, so it costs almost nothing
the rest of the time.

Forked from [SysReadout Launcher](https://github.com/AndSni/SysReadout-Launcher), which shows the
same data on the home screen.

## Status

In development; not released yet.
